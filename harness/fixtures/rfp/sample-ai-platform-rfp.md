# AI 플랫폼 사업 제안요청서 샘플

## 사업 개요

사업명: 공공 AI 분석 플랫폼 구축
발주기관: 샘플연구원
사업예산: 2,800,000,000 KRW
계약기간: 14개월
입찰방식: 협상에 의한 계약
제안마감일: 2026-08-21
업무도메인: AI/데이터
사업유형: AI 플랫폼 구축

## 과업 범위

기관 내부 데이터를 분석하여 예측 모델을 학습하고, 모델 운영, 모니터링, 설명 가능성, 데이터 거버넌스 체계를 포함한 AI 플랫폼을 구축한다.

## 기능 요구사항

1. 데이터 수집 파이프라인을 구축한다.
2. AI 모델 학습과 검증 화면을 제공한다.
3. 모델 배포 승인 워크플로를 제공한다.
4. 예측 결과 설명 가능성 화면을 제공한다.

## 비기능 요구사항

1. 모델 추론 API는 초당 30건 요청을 처리해야 한다.
2. 모델 성능 지표를 일별로 기록해야 한다.

## 보안 요구사항

1. 학습 데이터 접근 권한을 역할별로 제한한다.
2. 개인정보 포함 데이터는 비식별 처리 후 사용한다.

## 인프라 요구사항

1. GPU 학습 환경과 운영 추론 환경을 분리한다.
2. 모델 저장소와 데이터 카탈로그를 구성한다.

## 데이터 이관

1. 기존 분석 데이터셋을 신규 카탈로그로 이관한다.

## 제안 아이템

1. AI 모델 위험 점검 체크리스트를 제안한다.
2. 운영 담당자 대상 MLOps 교육을 제안한다.
