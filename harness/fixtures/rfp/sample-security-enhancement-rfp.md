# 보안 강화 사업 제안요청서 샘플

## 사업 개요

사업명: 공공 서비스 보안 강화 및 접근통제 고도화
발주기관: 샘플공단
사업예산: 760,000,000 KRW
계약기간: 7개월
입찰방식: 협상에 의한 계약
제안마감일: 2026-09-10
업무도메인: 보안
사업유형: 보안 고도화

## 과업 범위

기존 업무 시스템의 접근통제, 로그 관리, 취약점 조치, 관리자 권한 승인 체계를 고도화한다.

## 기능 요구사항

1. 관리자 권한 신청과 승인 기능을 제공한다.
2. 접근 정책 변경 이력을 조회할 수 있어야 한다.
3. 보안 점검 결과 리포트를 생성한다.

## 비기능 요구사항

1. 감사 로그 조회는 5초 이내 응답해야 한다.

## 보안 요구사항

1. 관리자 MFA를 적용한다.
2. 접근 로그를 위변조 방지 저장소에 보관한다.
3. 취약점 조치 이력을 증적과 함께 관리한다.

## 인프라 요구사항

1. 로그 수집 서버와 검색 노드를 분리한다.

## 제안 아이템

1. 보안 사고 대응 런북 자동화를 제안한다.
