# 유지관리 사업 제안요청서 샘플

## 사업 개요

사업명: 지자체 통합 행정 데이터 플랫폼 유지관리
발주기관: 샘플시 정보통신담당관
사업예산: 420,000,000 KRW
계약기간: 12개월
입찰방식: 제한경쟁입찰
제안마감일: 2026-07-03
업무도메인: 행정 데이터
사업유형: 유지관리

## 과업 범위

운영 중인 행정 데이터 플랫폼의 장애 대응, 정기 점검, 소규모 기능 개선, 보안 패치, 데이터 품질 점검을 수행한다.

## 기능 요구사항

1. 사용자 문의와 장애 티켓을 접수하고 처리 상태를 관리한다.
2. 월별 운영 리포트를 자동 생성한다.
3. 데이터 품질 오류 목록을 관리자가 확인할 수 있게 한다.

## 비기능 요구사항

1. 업무 시간 내 긴급 장애 2시간 이내 1차 대응을 보장한다.
2. 정기 배포는 월 1회 수행한다.

## 보안 요구사항

1. 보안 패치를 분기별로 적용한다.
2. 관리자 계정 권한을 반기별로 점검한다.

## 인프라 요구사항

1. 기존 온프레미스 서버와 백업 스토리지를 유지한다.

## 제안 아이템

1. 장애 유형별 자동 분류 대시보드를 제안한다.
2. 데이터 품질 추세 분석 리포트를 제안한다.
