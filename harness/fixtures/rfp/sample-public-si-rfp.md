# 공공 SI 사업 제안요청서 샘플

## 사업 개요

사업명: 도시 통합 민원 포털 재구축 및 AI 상담 지원 시스템
발주기관: 샘플광역시 디지털정책관
사업예산: 1,250,000,000 KRW
계약기간: 9개월
입찰방식: 협상에 의한 계약
제안마감일: 2026-06-12
업무도메인: 공공행정
사업유형: 시스템 구축 + AI 도입

## 과업 범위

시민 민원 포털을 모바일 중심으로 재구축하고, 통합 관리자 콘솔, 외부 본인확인 연계, 민원 처리 상태 추적, 통계 대시보드, AI 상담 지원 기능을 제공한다.

## 기능 요구사항

1. 시민 민원 포털 화면을 모바일 웹 기준으로 재구축한다.
2. 통합 관리자 콘솔에서 민원 접수, 배정, 처리 상태를 관리한다.
3. 역할 기반 접근 제어와 관리자 승인 흐름을 제공한다.
4. 외부 본인확인 서비스와 연계하여 신청자 신원을 확인한다.
5. 민원 처리 상태 추적과 알림 발송 기능을 제공한다.
6. 부서별 통계 대시보드와 엑셀 다운로드 기능을 제공한다.
7. AI 상담 지원 모듈은 반복 민원 답변 초안을 제안한다.

## 비기능 요구사항

1. 모바일 360px 화면에서 주요 업무가 가로 스크롤 없이 동작해야 한다.
2. 초기 화면은 일반 모바일 네트워크에서 3초 이내 표시되어야 한다.
3. 주요 변경 이력은 감사 로그로 1년 이상 보존한다.
4. 장애 발생 시 관리자에게 알림을 전송한다.

## 보안 요구사항

1. 개인정보 마스킹과 다운로드 권한 제어를 적용한다.
2. 접근 로그와 관리자 작업 로그를 보존한다.
3. 취약점 진단과 시큐어 코딩 점검을 지원한다.

## 인프라 요구사항

1. 공공 클라우드 환경에 이중화 구성을 적용한다.
2. 운영, 검증, 개발 환경을 분리한다.

## 데이터 이관

1. 기존 민원 데이터 5년치를 신규 포털로 이관한다.
2. 첨부파일 일부는 파일명 규칙이 불명확하므로 사전 정비가 필요하다.

## 제안 아이템

1. 실시간 운영 KPI 대시보드를 제안한다.
2. AI 답변 품질 검수 워크플로를 제안한다.
3. 운영자 교육 영상과 매뉴얼을 제공한다.
